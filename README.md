# CodeReview

CodeReview is an experimental, evidence-led pull request review harness.
It builds bounded review scopes from immutable Git evidence and records findings, coverage, and uncertainty.
The read-only candidate does not execute pull-request code or publish reviews.
A terminal `INCOMPLETE` result is not a clean review.
The analysis workflow and publication path have not been verified in a hosted repository.
Current pilot results are incomplete; production quality and Droid replacement are not established.
Live review publication remains disabled.
The initial implementation will be delivered through a pull request.
