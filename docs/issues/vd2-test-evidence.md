All effects are synthetic: provider requests go to loopback HTTP, and publication/GitHub calls use injected fakes. Provider rows assert the exact `ProviderError` reason in the failed task, an `INCOMPLETE` result, a `FAILED` settlement, exactly one provider POST, and no publication. SE-4 rows preserve their precise status/reason/POST/receipt-write contracts, including the non-fault acknowledgement control SE4-FM-01. Receipt writes are fake writer/upload calls, not proof of a durable live artifact.

The GitHub 429 row fails closed during read-only history scanning, before receipt upload or review POST. The GitHub 503 row is deliberately narrower: it occurs during history reconciliation after an ambiguous submit and preserves `UNKNOWN` with one prior POST and one receipt upload. The redirect row exercises the stateless publisher's admission boundary with a fake artifact API response: it returns `UNKNOWN` with reason `artifact_download_location_untrusted`, writes no receipt, posts no review, and makes zero artifact download calls for the untrusted URL. The separate adapter test confirms an allowlisted signed URL is downloaded through the tracked tokenless download interface. These rows are bounded scenarios, not claims that every GitHub endpoint or status is covered.

Conflicting budget replay remains covered separately by [test_conflicting_duplicate_attempt_replay_cannot_replace_terminal_failure](../../tests/test_vd2_provider_faults.py): a conflicting successful replay cannot replace the existing failed settlement or add outputs. It is not a provider duplicate-response scenario.

This is a bounded fault-acceptance evidence slice, not full VD-2 closure or live-provider/GitHub qualification. In the separate adapter test, the observed download call carries only URL, timeout, and response cap, while the API request transport receives the test token. The timeout fixture separates a bounded five-second isolated-process startup allowance from the provider's injected 0.05-second HTTP timeout; it does not change production deadlines or retry policy.

Current mutation artifacts show whole-module measurements for reconcile and budget, plus bounded function-only measurements for reducer and three validation functions. They do not qualify every reducer/validator module; mutation reports are evidence artifacts, not a mutation CI gate. Budget survivor triage remains summarized rather than individual. The acceptance index is synthetic and does not establish live-provider/GitHub qualification. VD-2 remains open.
