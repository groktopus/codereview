# Provenance and evidence note

This repository contains original harness code plus preserved review evidence,
frozen historical fixtures, and provider-free test artifacts. The MIT license
applies to the repository's original code and documentation.

Evidence artifacts are retained to make past observations auditable. They are
not current product claims, and a historical snapshot does not become current
because a later commit touches the repository. Provider outputs and target
repository content remain subject to their own terms; do not infer a license
for third-party content from this repository's license.

Code and documentation were produced with AI-agent assistance under human
direction and review. Committed evidence identifies the revision and artifact
it describes; estimates, reported facts, and unknowns remain labeled as such.
No target code executes in credentialed analysis, and no credentials are stored
in fixtures.
